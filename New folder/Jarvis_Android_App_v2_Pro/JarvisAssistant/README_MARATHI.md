# Jarvis AI Pro (Invisible + Multi-Language + Lock-Screen Wake-Word)

तुमच्या सर्व सूचनांनुसार हा **Jarvis v2.0 Pro** प्रोजेक्ट अपडेट केला आहे:

1. **मल्टी-लँग्वेज आवाज (Multi-Language Voice):** तुम्ही मराठी, हिंदी किंवा इंग्लिश ज्या भाषेत बोलाल, जार्विस त्याच भाषेत तुम्हाला उत्तर देईल.
2. **१००% अदृश्य बॅकग्राऊंड मोड (Invisible Background Mode):** अ‍ॅप एकदा सुरू केल्यावर ते स्क्रीनवरून पूर्णपणे गायब (`moveTaskToBack`) होते आणि कोणताही फ्लोटिंग बबल न ठेवता फक्त तुमच्या आवाजावर चालते.
3. **पैसे पाठवणे, मेसेज करणे, कॉल लावणे आणि एडिट करणे (विचारूनच होईल!):**
   - कोणालाही **फोन लावण्यापूर्वी** जार्विस तुमच्या Contacts मधून नाव शोधून विचारतो: *"सर, मी राहुल यांना कॉल लावू का? हो किंवा नाही सांगा."*
   - **पैसे पाठवणे (UPI)**, **मेसेज पाठवणे (SMS/WhatsApp)** आणि **एडिट करणे** या कामांसाठी तुम्ही **"हो" (किंवा "Yes / हां")** म्हटल्याशिवाय जार्विस पुढचे पाऊल उचलत नाही.
4. **बाकी सर्व कामे थेट आवाजाने:** स्क्रोल अप/डाऊन, बटनावर क्लिक करणे, कोणतेही अ‍ॅप उघडणे, आवाज कमी-जास्त करणे, बॅक/होम करणे ही सर्व कामे परवानगी न मागता लगेच होतात.
5. **स्क्रीन लॉक असतानाही वेकवर्ड चालू (Lock-Screen WakeLock):** मोबाईल दूर ठेवलेला असेल आणि स्क्रीन लॉक असेल तरीही `PARTIAL_WAKE_LOCK` आणि `Unrestricted Battery Mode` मुळे *"Hey Jarvis"* किंवा *"OK Jarvis"* म्हटल्यावर तो लगेच जागा होतो.
